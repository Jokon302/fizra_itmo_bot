# 🏸 ITMO Sport Bot (Бот для физры ИТМО)

[![Python](https://img.shields.io/badge/Python-3.12-blue.svg)](https://www.python.org/)
[![Docker](https://img.shields.io/badge/Docker-compose-2496ED.svg)](https://www.docker.com/)
[![ITMO](https://img.shields.io/badge/ITMO-my.itmo.ru-red.svg)](https://my.itmo.ru/)

Многопользовательский Telegram-бот для мониторинга расписания, отслеживания свободных мест, мгновенной записи и подсчёта баллов по физической культуре в Университете ИТМО ([my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign)).

---

## 🚀 Основные возможности

- 🔍 **Поиск слотов на 3 недели вперёд:**
  - Сканирование актуального расписания через официальное API ИТМО.
  - По умолчанию отображаются только доступные для записи слоты с ненулевым остатком мест.
  - Возможность просмотреть полную сетку (включая занятые слоты `0/20`).

- ⚡️ **Запись и отписка в 1 клик:**
  - Кнопка «✍️ Записаться» прямо под карточкой найденного слота.
  - Раздел «📅 Мои записи» с просмотром всех активных записей и быстрой отпиской.

- 🤖 **Автозапись:**
  - Опциональный режим автоматической отправки заявки при появлении свободного места в нужный день и время.

- 🏆 **Баллы и посещения:**
  - Прогресс-бар баллов за текущий семестр до зачёта (100 баллов).
  - Подсчёт оставшихся занятий, история последних начислений и баланс свободных записей.

- 👥 **Мультиаккаунт для друзей:**
  - Изолированное хранение авторизационных токенов и фильтров каждого пользователя.
  - Вход через `id.itmo.ru` прямо в ЛС бота (сообщение с паролем удаляется автоматически).
  - Кнопка полного удаления своих данных из бота в любой момент.

- 💤 **Защита от неактивности:**
  - Если пользователь не взаимодействует с ботом более 21 дня (3 недели), ежечасный фоновый поиск автоматически ставится на паузу для снижения нагрузки.

- 💬 **Работа в групповых чатах:**
  - Поиск свободных мест для всей компании (`/slots Бадминтон`).
  - Командный топ по баллам за семестр (`/board`).

- 👑 **Админ-панель:**
  - Просмотр зарегистрированных пользователей и их статусов (`/users`).

## 📂 Структура проекта

```text
├── bot.py              # Основной Telegram-бот, планировщик и обработка команд
├── itmo_client.py      # Клиент к my.itmo.ru и OAuth2 PKCE аутентификация ITMO ID

├── docker-compose.yml  # Декларативный запуск с сохранением данных в volume
├── requirements.txt    # Зависимости (httpx, python-dotenv)
├── .env.example        # Шаблон переменных окружения
└── .gitignore          # Правила исключения временных файлов и секретов
```

## 🛠 Быстрый старт

### Вариант 1: Запуск через Docker Compose (Рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<your-username>/itmo-sport-bot.git
   cd itmo-sport-bot
   ```

2. Создайте файл `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```

3. Укажите в `.env` токен вашего бота (от [@BotFather](https://t.me/BotFather)) и ваш Telegram User ID:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
   ADMIN_USER_ID=123456789
   ```

4. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

5. Проверьте логи:
   ```bash
   docker compose logs -f
   ```

---

### Вариант 2: Локальный запуск без Docker

1. Установите Python 3.11+:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Linux/macOS
   # или .venv\Scripts\activate в Windows
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Заполните `.env` и запустите бота:
   ```bash
   python bot.py
   ```

## ⚙️ Переменные окружения (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от Telegram [@BotFather](https://t.me/BotFather) | *Обязательно* |
| `ADMIN_USER_ID` | Telegram ID администратора (для `/users`) | `0` |
| `CHECK_INTERVAL_MINUTES` | Интервал фонового поиска слотов (минуты) | `60` |
| `AUTO_SIGN_UP` | Автоматическая запись по умолчанию | `false` |
| `DATA_DIR` | Путь к каталогу с базой `users.json` | `data` |

## 📱 Список команд бота

### В личных сообщениях:
- `/start` — панель управления и меню.
- `/check [секция]` — поиск открытых слотов со свободными местами.
- `/all [секция]` — все слоты на 3 недели (включая занятые).
- `/score` — текущие баллы за физкультуру и прогресс до зачёта.
- `/my` — просмотр будущих занятий и отписка.
- `/settings` — настройка секций, дней недели, времени и корпусов.
- `/login <ИСУ> <ПАРОЛЬ>` — авторизация через ITMO ID.
- `/delete_me` — удаление своих данных и токенов из базы.
- `/users` *(только для админа)* — список всех пользователей бота.

### В групповых чатах:
- `/slots <секция>` — показать доступные слоты для группы.
- `/score` — показать свои баллы в беседе.
- `/my` — показать свои записи.
- `/board` — соревновательная таблица лидеров по баллам среди участников.

## 🔒 Безопасность

- Бот **не хранит пароли в открытом виде** в исходном коде.
- При вводе логина и пароля в Telegram бот мгновенно удаляет сообщение пользователя из переписки.
- Полученные токены `access_token` и `refresh_token` хранятся в защищённом JSON-файле внутри Docker volume (`/app/data/users.json`).
- В групповых чатах команда `/login` блокируется, а сообщение немедленно удаляется во избежание утечки учетных данных.
